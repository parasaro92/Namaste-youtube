# Namaste YouTube

This React app uses Vite and Tailwind CSS v4.

## Scripts

- `npm start` starts the Vite development server.
- `npm test -- --watchAll=false` runs the existing React test suite once.
- `npm run build` creates a production build in `dist`.

Tailwind is enabled through the Vite plugin. Import Tailwind with
`@import "tailwindcss";` in `src/index.css`, then use utility classes in
components.
